# board-watch Skill（主动 + 执行）

## 名称
board-watch

## 描述
板载守望：周期性巡检空闲时间与堆状态；超阈值时**主动**触发 LED 告警执行。
按键边沿也可主动触发闪灯。

## 触发
- 定时巡检（默认 15s）
- 用户输入 `inspect`
- 用户按键事件

## 阈值与执行
| 条件 | 执行 |
|------|------|
| 空闲 ≥ idle_alert 秒 | 闪烁 LED2 |
| 可用堆 < 2KB | 点亮 LED3 |
| 按键按下 | 闪烁 LED1 |

## 说明
满足赛道「主动 + 执行」要求，且**零外设**。
